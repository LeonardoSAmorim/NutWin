THtmlHelp component

THmlHelp component converts the help calling convention of a delphi application to HtmlHelp.

In captures the OnHelp event and launch the help using a help context.

You must build the .chm files, see HtmlHelp files for more info.

Property Datatype Description Type
ChmFile String You can set the file to be opened when the application help is called Published
Windef String

When you build a HTML Help file you can create window definitions, the window definition name can be set here

 Published
DefaultFile String If you do not set the ChmFile property the application will search changing the extension of the exe application to chm. Published
Password String Password used executing all operations Published
Destination String Filename (UNC also accepted) destination for backups and source for restore operations Published
ShowProgress Boolean Shows or not a windows with a progres indicator (strings provided by the administration commands), you can calcel the proces. Published

 

Method definition Description
function HelpContext(ContextId: DWord): Integer; Calls the help with a contextid, it's called when the F1 key is pressed and a the HelpContext property of a form is set.
function HelpTopic(Topic: String): Integer; Calls the help with a help topic
function ShowIndex:integer; Shows the index page of help file
function ShowTableofContents:integer; Shows the table of contents of the help file
function ShowSearch:integer; Shows the search tab of the help file
