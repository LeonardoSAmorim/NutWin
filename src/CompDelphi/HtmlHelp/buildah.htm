Building a HtmlHelp File for use with Delphi

This is a small tutorial to learn how to build a HtmlHelp file for use with Delphi

Step 1. Write the web pages

You can use any web page editor or a text editor. Don't use propietary extensions.

Step 2. Build a topic file definition

A c header file like constant.h

#define HC_TOPIC1 101

#define HC_TOPIC2 102

Step 3. Create the project with HTML Help Workshop

Add your htm files to the project, set the options, and I recommend to create a Index and a Help contents. You can download the Html Help Workshop for free from here.

Step 4. Link the numbers with the topics

You must link the definitions of the constant.h file to the topics.

  1. Click API Html Help Information
  2. Click Header file button and select the constant.h help file
  3. Go to the alias Tab and click Add Button for every topic you must enter the defina name like HC_TOPIC1 and select the web page to link to.

Step 5. Build the help and test help context it with Html Help Workshop

Step 6. Link help with the delphi application

Drop the THmlHelp component on the Mainform of the project, write the filename and window definition (optional) and set the Help Context of every component. If you press F1 the correct topic is show.

Optional steps

  1. Create a window definition, you can select to show locate buttons etc.
  2. Create a full text search index (click properties) and include stop search file with words like "and,yes,no" that will not be included in the index.
  3. Change options of table of contents.
