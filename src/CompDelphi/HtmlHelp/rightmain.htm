Description

Html Help for Delphi is a component that implements the Html Help into a Delphi application.

You must drop the component to the main form and pressing F1 will cause the launch of the .chm file insted of the .hlp file.

It's simple, it's easy, it's free and it's opensource:

You can install the package to your delphi enviroment.

Remember to set a correct library path on enviroment options to compile your applications.

See THtmlHelp for detailed info about properties and methods.

And it's opensource...and also a sample application is provided.
