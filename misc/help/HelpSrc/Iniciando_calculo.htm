Iniciando um cálculo

Para criar um novo arquivo ou abrir um já existente, usar os botões ou menu em arquivo.

Caso seja um novo arquivo, selecione um dos tipos de cálculo nos botões ou menu em cálculos, para visualizar ou imprimir o resultado. Pressione, então, a opção Calcular.

Para cada novo cálculo solicitado é apresentada uma tela de entrada dos dados básicos do indivíduo, também chamado de Dados de Escopo. Estes dados vão identificar e definir quais tipos de cálculo podem ser realizados, portanto, estes não poderão ser alterados após a sua entrada.

Data da Visita: para efeito de cálculo da idade.

Nascimento: para cálculo da idade.

Anos, Meses e Dias: podem ser digitados ou calculados, definindo a faixa etária.

Sexo: Feminino ou Masculino.

Peso Atual: mensurado ou informado. Necessário para definir algumas tabelas de percentil.

Estatura: mensurado. Necessário para definir algumas tabelas de percentil.

Gestante a: indica ao mesmo tempo se é gestante (<> 0 ) e a quanto tempo.

Nutriz a: indica ao mesmo tempo se é nutriz (<> 0 ) e a quanto tempo.
