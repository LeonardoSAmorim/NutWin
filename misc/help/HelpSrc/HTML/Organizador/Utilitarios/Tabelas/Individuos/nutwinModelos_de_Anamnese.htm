Cadastro de Modelos

Para cadastrar um modelo de anamnese, vá no menu Utilitários/ Tabelas/ Indivíduos/ Modelos para Anamnese.

O Nome é utilizado para identificar o modelo.

O campo Modelo aceita qualquer texto, quer seja digitado ou colado de outros editores de texto. Utilize a barra com opções para formatação situadas acima do campo. Pode-se escolher fonte da letra, tamanho, cor, etc.

O botão “Visualizar” mostra em formato de relatório, todos os Modelos cadastrados.

Visualização de Modelos

Para trazer um Modelo cadastrado, basta utilizar o botão Modelo situado a direita da tela de cadastro.

Escolha pelo nome o modelo desejado e clique no botão OK. Será incluído no cadastro. Está liberado para alterações.
