Equipamento necessário

  • Requisitos mínimos: Microcomputador PC ou compatível, com processador Pentium 300 MHz, 64 MB de memória RAM, 80 MB de espaço disponível no disco rígido, resolução de 800X600, Windows 9x, Me, 2000, XP ou NT;

  • Configurações Regionais (Painel de Controle) ajustadas para Português-Brasil; vírgula como separador de casa decimal e "dd/mm/aaaa" para data abreviada.
