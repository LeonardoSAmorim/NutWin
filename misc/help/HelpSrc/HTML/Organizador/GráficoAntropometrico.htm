Gráficos Antropométricos de Acompanhamento

O programa gera alguns gráficos antropométricos.
Escolha o cálculo que desejar, não esquecendo de completar as datas de início e fim. O programa verifica se existem dados suficientes para gerar o gráfico.

Verifique a funcionalidade dos seguintes botões:

Visualizar - mostra o gráfico no espaço disponível.

Ampliar linha - aumenta o gráfico, deixando a linha centralizada.

Imprimir - imprime o gráfico em formato de relatório.

Fechar - retorna para a tela de Indivíduos.
