Botões

Veja o significado dos botões utilizados no programa :

Primeiro - posiciona diretamente no primeiro registro do Banco de Dados.

Anterior - move para um registro anterior ao atual.

Próximo - move para um registro a frente do atual.

Último - posiciona imediatamente para o último registro da Base de Dados.

Incluir - acrescenta um novo registro a Base de Dados.

Salvar - grava os dados na Base de Dados.

Editar - altera os dados na Base de Dados.

Excluir - apaga o registro da Base de Dados.

Cancelar - anula a operação realizada.
