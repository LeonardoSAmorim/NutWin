Como exportar dados do programa

A Exportação de Dados visa transferir informações Antropométricas e de Inquérito para outros programas tais como : arquivo txt, word, excell e outros.

Siga os seguintes passos :

Selecionar indivíduos

Completar dados

Conferir informações

 

 

 

Selecionar Indivíduos

Existem duas opções para selecionar indivíduos :

Por Pastas: Esta opção disponibiliza uma tela com duas caixas. Devem ser escolhidas as Pastas que serão pesquisadas. A seleção é feita passando para a direita somente as Pastas desejadas. Use o botão avançar para continuar a pesquisa.

Trabalhar com todos os indivíduos: Quando é escolhida esta opção, o programa utiliza toda a base de dados dos indivíduos cadastrados.

 

 

Completar Dados

É necessário informar ao programa a data inicial e final corretas, o local para a gravação do arquivo TXT e as informações que deseja que sejam geradas.

O programa fará um filtro sobre os dados, gerando somente os que estiverem dentro do padrão selecionado.

 

 

Conferir informações

Os dados selecionados na tela anterior serão apresentados novamente para conferência.

Caso esteja algo errado, utilize o botão Voltar. Estando tudo correto, use o Terminar.

Após terminada a pesquisa, o programa grava o arquivo no local que você escolheu.

Basta abrir no Excel ou em algum editor que leia arquivos txt.
