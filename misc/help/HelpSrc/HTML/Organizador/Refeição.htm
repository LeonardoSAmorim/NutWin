Refeição

Para se cadastrar uma refeição e associá-la a um modelo, conheça melhor cada um dos itens abaixo:

  • Cadastro de Refeições

  • Lista de Modelos

  • Refeição

  • Visualização

Cadastro de Refeições

Neste módulo deve ser cadastrado o nome da refeição a ser usada no Plano Alimentar e Inquéritos.

 

Lista de Modelos

Neste módulo deve ser cadastrado o nome do Modelo de Refeição a ser usada no Plano Alimentar e Inquéritos.

 

Refeição

Associe um Modelo a sua Refeição. O programa já tem o Modelo Padrão, com as refeições costumeiras.

O horário indica a ordem em que aparecerá no programa.

 

Visualização

Este módulo existe somente para facilitar a visualização dos Modelos e suas Refeições..

Escolha o modelo disponível e verá logo abaixo a lista das refeições cadastradas.
