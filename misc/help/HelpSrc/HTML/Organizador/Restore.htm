Restaura Cópia de Segurança (Restore)

Para restaurar sua Cópia de Segurança, siga os seguintes passos:

1- Selecione o arquivo a ser recuperado.

Caso esteja armazenado em disquete, coloque o primeiro da série para que o programa reconheça.

2- Certifique-se de que o arquivo a ser restaurado está correto, observando atentamente o Título da Cópia.

3- Escolha o local para recuperar o arquivo.

Se selecionar Diretório Original, a base de dados será sobreposta.

Caso utilize outro caminho, copie depois para o subdiretório do Programa Nutrição onde está o Banco de Dados.

4- Tecle Recuperar para restaurar o backup ou Fechar para cancelar a operação.
