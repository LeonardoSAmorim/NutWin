Configurando sua Calculadora

Este comando permite a configuração, de acordo com o usuário, dos seguintes tópicos:

  • Antropometria

  • Nutrientes

 

Configurando Antropometria

Aparecerá uma lista de Cálculos Antropométricos disponíveis. Selecione os que deseja ver nos relatórios do programa. Para marcar todos os cálculos, utilize o botão Todos.

Com o botão Nenhum, o programa desmarca os cálculos.

 Valide com o botão OK.

Configurando Nutrientes

Marque os Nutrientes que deseja que apareçam para acompanhamento no programa.

Podem ser ordenados pela ordem padrão ou por nome. A Ordem padrão é aquela definida pelo usuário.

Caso deseje trabalhar com todos os Nutrientes, marque a opção "Acompanhar todos os Nutrientes (temporariamente)".

A opção "Ver os Escolhidos", disponibiliza na tela somente os Nutrientes selecionados.
