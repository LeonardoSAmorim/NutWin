Introdução

A calculadora funciona como um gerenciador de documentos (.NUT), cujo o conteúdo consiste de um ou mais tipos de cálculos para um determinado indivíduo, ou seja, um documento corresponde a um único indivíduo. Os dados do indivíduo são apenas os necessários para os cálculos, sendo os demais solicitados pelo organizador quando no armazenamento.

As funções de gerenciamento destes documentos podem ser acessadas pelos menus ou pelos botões, são elas:

Arquivo

  • Novo

  • Abrir

  • Fechar

  • Salvar e Salvar como

  • Sair

As funções que acessam os Cálculos são as seguintes:

Cálculos

  • Antropometria

  • Recomendações de Energia

  • Atividades Físicas

  • Preparação

  • Inquérito

  • Plano Alimentar

  • Calcular (executa o Cálculo ativo)

  • Visualizar

Os cálculos podem ter a sua operação ou saída configurada pelas seguintes funções:

Configurar

  • Antropometria

  • Nutrientes

Ajuda
