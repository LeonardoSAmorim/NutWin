Relatório de resultados

Ao escolher o botão Terminar, os cálculos são efetuados e tanto seus parâmetros e resultados são apresentados na janela principal do programa. Este relatório pode ser “ampliado” e impresso, utilizando a opção Visualizar. Para imprimir, utiliza-se o botão com uma impressora no canto superior esquerdo.

Se o botão escolhido foi cancelar, o relatório mostrado estará vazio ou dos valores anteriormente digitados e calculados.

Este cálculo pertence a família dos cálculos alimentares, portanto os demais se comportam de modo semelhante. A seqüência de janelas é a seguinte:

1. Seleciona Refeições

Nesta janela são selecionadas as refeições do inquérito. Se não for escolhida nenhuma refeição, o inquérito é considerado global. Além das refeições enviadas com o sistema, o usuário pode cadastrar outras no organizador.

2. Consumo em

Aqui, é digitado o número de dias que o consumo corresponde. Este número será usado para dividir os nutrientes para saber o consumo diário.

3. Inquérito de Consumo

A janela é dividida em 2 partes no sentido horizontal e vertical. A esquerda, no sentido vertical, está a lista de alimentos disponível para se fazer o inquérito. A direita, no mesmo sentido, está o inquérito alimentar a ser montado. Já na parte superior, no sentido horizontal, está a representação visual para o processo de montagem e, na parte inferior, no mesmo sentido, está a representação caracter e todos os resultados possíveis.

Portanto, para adicionar/retirar um alimento ao inquérito, basta selecionar um alimento na lista (pode-se usar uma série de opções para localizar, filtrar ou ordenar a lista); clicar e arrastar da lata para o prato ou usar o botão Adicionar. Para retirar um alimento do inquérito e só fazer o processo inverso (do prato para a lata). No processo de adicionar, se o alimento tiver medidas caseiras, aparecerá uma janela para selecionar a medida e a sua quantidade. Caso o alimento não tenha medidas caseiras ou se deseje entrar em gramas, é só digitar o valor no campo peso, ao lado do prato, antes de adicionar.

Clicando nos livros, abre-se uma janela com os valores dos nutrientes do alimento que está na lata.

Além de poder selecionar as refeições através dos botões de navegação, clicando no relógio de parede, aparece uma janela com as refeições escolhidas.

Pode-se Cancelar o cálculo no botão Cancelar ou Confirmar o cálculo no botão Ok.

4. Relatório de Resultados

O relatório de inquérito é semelhante ao exemplo acima (no caso preparação), só que com a identificação do indivíduo, as refeições escolhidas e a lista de alimentos medidas e pesos de cada refeição, além dos totais de nutrientes.
