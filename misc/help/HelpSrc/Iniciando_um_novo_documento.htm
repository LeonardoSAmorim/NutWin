Iniciando um novo documento

Para cada novo documento solicitado é apresentada uma tela de entrada dos dados básicos do indivíduo, também chamado de dados de escopo. Estes dados vão identificar e definir quais tipos de cálculo podem ser realizados. Portanto, não poderão ser alterados após a sua entrada.

Após terminado o preenchimento do escopo, o programa verifica a validade das informações. Uma tela de Consistência das Informações do Indivíduo aparecerá.

A partir daí estarão disponíveis todos os cálculos.
