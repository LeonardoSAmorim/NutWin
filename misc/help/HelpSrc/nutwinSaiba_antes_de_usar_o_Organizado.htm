Saiba antes de usar o Organizador

Para conhecermos os cadastros, precisamos entender sua funcionalidade. Aqui estão descritas as mais importantes e usadas no Organizador inteiro:

Novo e Incluir – Este comando cria um registro em branco, pronto para receber novos dados.

Editar – Deixa a base de dados preparada para receber correções em dados já cadastrados.

Excluir – Este comando implica na remoção de todas as informações cadastradas e associadas para o registro corrente. Uma vez confirmada a exclusão, não haverá como recuperar o registro.

Cancelar – Anula as alterações feitas no registro.

Salvar – Grava em disco as informações entradas no programa, pelo comandos Novo, Incluir ou Editar.
