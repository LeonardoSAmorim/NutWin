Duplica Alimento

Caso algum alimento seja muito similar a outro, pode-se utilizar esta funcionalidade para duplicar o alimento.

Serão copiados os nutrientes com os mesmos valores.

  1. Para Duplicar Alimento siga os seguintes passos :

  2. Selecione o alimento a duplicar

  3. Altere o nome do alimento e preencha a origem. Ele aparecerá com um número na frente do nome para indicar que é uma cópia.

  4. Na lista de alimentos, aparecerá em azul, indicando que foi duplicado.
